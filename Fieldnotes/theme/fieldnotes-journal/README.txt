Fieldnotes Journal 1.9.0
Markets、京东选购与统一排版

安装
----
在 WordPress「外观 > 主题 > 安装主题 > 上传主题」上传 fieldnotes-journal-1.9.0.zip，替换当前主题。目录仍为 fieldnotes-journal，不附带插件 ZIP；已安装的 ChatGPT、Travel Map、Comment Tools 继续使用，不重置插件设置。升级后使用管理员账号进入一次后台，再清理站点、CDN 和浏览器页面缓存。
上一版对 Wayfarer / Keepsakes 使用过 301 跳转；新版为这两个独立页面使用稳定的 view 地址标记，避免沿用旧跳转或形成缓存循环，页面 ID 不变。仍建议清理站点和浏览器缓存。
本包未直接部署到你的服务器。若仍出现 upload_max_filesize 错误，可将实际服务 WordPress 的 PHP 配置设为 upload_max_filesize=8M、post_max_size=16M 并重载 PHP-FPM；命令行 PHP 的配置不一定是网页使用的配置。

页面关系
--------
Boughs：五个入口组成的画廊，不再是分类清单。
城市漫步：独立文章页面，显示随笔与日常；不嵌地图，只提供前往 Wayfarer 的文字链接。
WordPress主题与插件：独立的组件介绍页，展示 Journal 主题与 ChatGPT、Map、Comment Tools 三个插件。
间隙拙作：独立的实践与仓库页面，保留 CROlordCloudNative / CROlordCodelibrary 入口，等待你发布云原生实践文章。
Markets：直接使用原 Gleanings 页面（同一个页面 ID 与地址），前台导航及标题改为 Markets；不再显示旧的按年归档。
Keepsakes：继续使用原页面 ID，承接败家极简的收藏与使用文章；不跳转到分类页。
Wayfarer：恢复原 Travel map 模板与地图样式，不跳转到城市漫步，也没有“行走与随笔”文章板块。

子栏目不显示 Boughs 面包屑、分类前缀或五项分类切换栏。旧的五个分类地址转到各自独立页面，保留股票代码、图表周期、收藏筛选和分页参数。首页主视觉、文章阅读宽度及评论样式保留；首页文章入口转到城市漫步，避免误进投资页。

Echoes 的页头
-------------
输入口令前：显示网站标识、栏目导航和小搜索入口。
通过口令、进入对话后：仅显示左上角固定 Logo，不输出栏目导航与搜索，滚动也不会重新出现。
重新锁定、口令错误、会话过期或被插件限制访问时：回到口令页，恢复正常导航。
页头状态取自 ChatGPT 插件实际渲染的会话结果，不通过“存在 Cookie”判断解锁，不复制插件的验证规则。解锁、锁定、文件上传与 MCP 权限仍由原插件负责。保留原 HTTP 测试设置。务必将 Echoes 从整页缓存中排除；插件本身也发送不缓存响应头。
无需为本次主题升级另装一个 ChatGPT 插件；兼容已交付的 Fieldnotes ChatGPT 1.5.0。

Markets
-------
支持中文名称与沪深北六位股票代码，或 SH600519、SZ000001、BJ920002、600519.SH 等格式。当前不提供美股、港股和指数查询。
图表支持分时、日 K、周 K、月 K。K 线保留前复权/不复权、MA5/10/20、成交量、缩放与数据表。
分时图使用数据源实际返回的分钟价格和每分钟成交量，午休从时间轴中折合，不补画缺失数据或未来走势；昨收有效时显示参考线与涨跌幅。分时模式不显示历史 K 线的复权与缩放选项。轻触或左右方向键可查看对应时间与价格，图下数据表显示最近 20 条。
这是公开站点数据接口，不是有服务承诺的授权行情 API，可能因网络、限流、接口变化或股票覆盖而不可用。当前实测读取过腾讯日线及分时；部署后的可用性仍需以你的服务器为准。历史数据可以继续通过 fieldnotes_market_series 过滤器接入自有授权源。

观察与复盘
----------
使用轻量统计和文章卡片；选择股票后筛选对应记录。草稿不公开，也不计入已发布数量。密码保护文章不公开其摘要。
有写作权限的账号登录后，可以在图表下方“写一段观察”，保存为本人草稿，再进入 WordPress 编辑器完善与发布。不会自动发布。
后台新建文章也可在“投资观察 · 股票代码”侧栏填写代码；填写有效代码后归入投资理财。一般理财文章可以留空股票代码并手动选择投资理财分类。
Keepsakes 的条目使用同样克制的标题、说明、筛选与内容布局，不再重复套一层分类页。

1.9.0 更新说明
--------------
Echoes 与 Boughs 使用主题同一套系统字体、字重、标题比例和中性色。Apple 设备优先使用系统 SF/PingFang，不分发 Apple 字体；其他系统使用可用的中文系统字体。Echoes 仍在口令验证前显示导航、搜索，验证通过后只留左上角标识。

Markets：导航、独立页面及 Boughs 入口统一使用英文名称 Markets；后台投资理财分类及原页面 ID、网址保持不变。
输入中文名称、名称简拼或六位代码检索沪深北 A 股。相近名称展示候选列表；可用方向键及回车选择。中文输入法组词期间不会提前提交。检索不可达时仍可直接输入代码。
报价、分时图与 K 线支持 2/5/10/30 秒自动尝试刷新，默认 5 秒，也可暂停；只在工作日上海时间 09:30–11:30、13:00–15:00 自动轮询，页面隐藏时暂停，失败时退避至最长 60 秒。此时段判断不包含法定休市日历；节假日仍可能尝试请求。图表视图、缩放和股票选择保留。
报价显示行情源提供的时间（精确到秒），图表显示自身数据时间；秒级请求频率不代表行情源逐秒产生数据，也不保证无延迟。历史/分时/报价按股票共享 2 秒缓存、并发锁与请求限额；失败显示原时间的缓存或明确错误，不生成模拟价格。
临时自选：成功查询后自动保存最多 12 只股票，可点击切换、移除或清空；仅使用 sessionStorage，在当前标签页刷新后保留，关闭标签页结束。浏览器禁止存储时可继续查行情。
数据请求由 WordPress 服务器发起：需可访问 HTTPS 腾讯证券/东方财富；不在浏览器存储密钥。公开源可能调整字段或限制访问，错误会明确展示。

Keepsakes：增加京东网页搜索、每件物品的京东入口、批量勾选、跨筛选/分页保留的临时选购清单、清单复制和京东购物车结算入口。
在后台「Faves / 收藏」编辑物品，在「Keepsakes · 京东选购」填写具体规格的京东商品编号或 item.jd.com 商品网址；留空则使用标题/搜索关键词到京东查找，不会伪造 SKU。
选中多件后打开「查看选购清单」，逐件到京东确认规格并加入购物车，再使用「去京东购物车结算」统一结算。清单不代表已加购：本站未取得京东账号及官方交易授权，不能把本地多选直接写入京东购物车；真正一键批量加购需要额外接入已获授权的京东能力。价格、库存、加购与下单结果由京东确认，本站不采集京东密码、不自动下单、不处理支付。

WordPress主题与插件：四个组件都提供可直接安装的 ZIP 下载及 GitHub 源码链接，独立维护，不将插件包塞进主题。
