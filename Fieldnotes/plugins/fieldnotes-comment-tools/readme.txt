Fieldnotes Comment Tools
Version: 1.6.0

评论自动审批与内容规则
--------------------
正常评论可以自动公开；命中待审规则的评论先不公开；命中管理员明确配置的禁止词时拒绝提交。
本地规则不依赖 API Key，不调用 AI 服务，不把评论发送到外部审核平台。它不是完整的语义审核：谐音、暗示、新词可能漏检，引用或讨论也可能命中，所以内置词表默认只转待审，不直接删除。

安装与开启自动通过
------------------
1. WordPress 后台「插件 > 安装插件 > 上传插件」，上传 fieldnotes-comment-tools-1.6.0.zip，并替换 Fieldnotes Comment Tools。
2. 进入「设置 > 讨论」。在「评论显示之前」取消「评论必须经人工批准」和「评论者必须曾有评论通过审核」（翻译可能略有差异）。这样新访客的正常留言也可以自动通过。
3. 在同页「Fieldnotes · 留言审核」保持「启用本地留言规则检查」，根据需要调整词表和链接阈值，再点击「保存更改」。默认已启用本地检查。
4. 清理页面与 CDN 缓存，再刷新浏览器。无需更换主题。

插件不会替你改动上述两项 WordPress 原生设置，也不会强制放行其他规则判为待审的评论。若仍开启人工审批，正常留言仍会待审；已有反垃圾插件、WordPress 待审词、禁止名单、链接规则与发言频率限制继续有效。

规则与后台配置
--------------
- 正常留言：规则检查不改变 WordPress 原有审批结果。在关闭两项人工审批限制后，一般直接公开；其他反垃圾规则仍可拦截。
- 待审词：内置少量辱骂、威胁、色情推广与广告短语。命中后不直接公开，在评论管理页保留待审原因，你可以批准、删除或标记垃圾评论。内置词表可以编辑、删除，不是全面的不良内容词库。
- 禁止词：默认留空。你明确填写后，命中内容拒绝提交，并提示修改；不会保存成评论。只将确定不允许提交的表达放在这里。
- 链接阈值：默认包含 2 个或更多不同的 HTTP(S)/www 地址时待审。相同地址在超链接目标和显示文字中重复出现不重复计数。无协议裸域名、短链含义与链接目标内容不在本规则的识别范围；WordPress 自身链接限制继续生效。
- 超长或格式异常：单个昵称、正文、网站字段超过 20000 字节或格式不符合预期时转待审，避免大量输入拖慢词表检查。

词表每行一个表达，每份最多 200 行，每行最多 96 字节，超出时后台提示未保存。检查昵称、正文与网站地址；不会将邮箱、IP、浏览器标识纳入这份内容词表，相关规则可继续使用 WordPress 原生设置。
匹配忽略大小写，处理全角字母、零宽字符、HTML 实体以及词中穿插的空格和标点。拉丁词避免命中无关单词内部。规则不支持正则表达式；不要填写过短或含义过宽的单字。
归一化只用于检查副本，不改变保存的正文、图片表情、昵称或头像。

与原版本保持一致
----------------
保留 1.5.4 的头像修复：邮箱头像继续使用 WordPress 原有来源与 srcset，不强制改成转发地址；预览真正加载成功后才确认匹配。已有本地头像选择仍有效。
前端 CSS、JavaScript、头像素材及 59 枚 SVG 图片表情均与 1.5.4 逐字节相同。昵称与邮箱必填、评论框、头像规则、留白、字体以及表情选择、输入、发表行为保持原样。
本次规则仅处理新提交的普通评论。旧评论、旧待审队列不会自动重新审批或删除，后台仍可人工处理。

安装后验证
----------
先取消两项人工审批限制，确认规则检查已启用；如启用其他反垃圾服务，仍需符合其规则。
- 在无痕窗口发表正常文字并插入一张图片表情，应直接显示；换一个未登录窗口确认能看见。
- 在待审词末尾添加「仅测试待审词」并保存。提交包含此短语的评论，应进入待审队列；作者可能看见待审提示，其他访客不应看见该评论。
- 在禁止词添加「仅测试禁止词」并保存。提交包含此短语的评论，应提示修改，不生成新评论。
- 测试结束删除两条测试短语。确认旧评论头像和新评论图片表情依然正常。
