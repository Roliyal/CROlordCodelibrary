Fieldnotes Travel Map
Version: 1.4.0
Requires WordPress: 6.2+
Requires PHP: 7.4+

本次布局更新
------------
以 Fieldnotes Journal 1.6.4.2 的黑白灰、系统字体和留白比例重新设计旅行地图。
- 地图页使用一个清楚的主标题、简洁导语与真实足迹统计；不再叠加旧模板的大图标和等待提示。
- 桌面端采用左侧地点索引与右侧宽幅地图，组成一个浅灰画框。地点标题、说明、搜索、筛选、按钮与圆角均统一到主题风格，没有绿色悬停色。
- 地点索引按年份由新到旧排列，同年按名称排列。选中地点与地图标记互相对应，点击后展开该地点的游记卡片。
- 地点视图改为图片卡片陈列；选择地点可返回地图并展开详情。没有图片或图片加载失败时，保留简洁的本地图形占位，不出现破图。
- 手机端在地图与地点视图之间切换，不再上下挤放两个滚动面板；小屏筛选独立成行，搜索与筛选使用 16px 字号。
- 页面滚动不触发地图滚轮缩放。增加查看全部当前地点、清除筛选与底图重试；标记点击只滚动内部索引，不把整个网页拉到其他位置。
- 保留键盘焦点、控件名称与选中状态，尊重系统减少动态效果的设置。

底图与加载
----------
Leaflet 1.9.4、markercluster 1.5.3 的脚本、样式与图标随插件提供，从本站加载，不再依赖 unpkg。
默认仍使用 CARTO 浅色底图；配置 Mapbox 公共令牌与样式后继续使用该设置。在线底图采用灰度处理，与主题保持一致，服务商署名保留。
插件另包含 Natural Earth 陆地轮廓简图，从本站加载并预先按墨卡托投影切开经线接缝。外部底图不可用时，世界轮廓、地点标记、聚合与游记仍可使用；详细底图恢复后自动覆盖简图。
简图只有粗略陆地轮廓，没有道路、城市地名和行政边界。详细地图与已有远程照片仍需要对应服务可访问。本站页面与插件本身仍需正常加载，这不是离线网站或道路导航服务。
没有匹配地点时显示清除筛选入口；地图库异常时，地点视图和已发布游记链接仍保留。无 JavaScript 时也提供游记链接。

更新方法
--------
1. WordPress 后台「插件 > 安装插件 > 上传插件」，上传 fieldnotes-travel-map-1.4.0.zip，并替换已安装的 Fieldnotes Travel Map。
2. 清理 WordPress 页面缓存、CDN 缓存，并强制刷新浏览器。
3. 打开旅行地图页面，验证地图 / 地点切换、国家地区与年份筛选、游记链接，以及已有地点与坐标。
只需更新地图插件，不必替换主题。插件不迁移、不删除现有地点、文章、坐标、图片、游记关联或地图配置。

与主题结合
----------
当启用 Fieldnotes Journal 或其子主题，并且当前页面使用 templates/page-map.php 模板时，地图插件为这一页提供新版布局，仍调用原主题的页头与页脚，不修改主题文件。
其他页面和其他主题的模板不受影响；其他主题或普通页面可插入 [fieldnotes_travel_map]。
原地图页内容中已有地图短代码时只渲染一次；原有自定义说明保留。
字体沿用主题的系统字体栈：Apple 设备优先使用其系统字体与苹方，其他设备使用可用系统字体，不分发 Apple 字体文件。

已有功能保留
------------
后台独立地点管理、文章编辑器地点关联、Mapbox 地点搜索、预览图片、国家地区与年份、多个已发布游记、无游记灰色标记、聚合、GeoJSON / JSON / KML 导入和 GeoJSON 导出、国家地区列表均保留。
后台管理、地点写入、文章关联保存、导入导出与演示数据创建代码未改动。新增坐标范围校验会跳过数据中越界的地点，但不会删除这些记录；可在后台修正。
已有演示数据保留，更新不会强制重新生成。地点和游记统计来自当前已发布记录，关联多处地点的同一游记只统计一次，私密或未发布游记不会出现在公开地图中。
后台地点搜索仍需 Mapbox 公共令牌；前台检索已有地点不需要令牌。请继续使用受网站域名限制的公共令牌，不输入私有密钥。

短代码
------
[fieldnotes_travel_map]
[fieldnotes_travel_map height="680" zoom="3" cluster="false"]
[fieldnotes_travel_map filter="false"]
[fieldnotes_travel_countries]
height 设置允许的最大画布高度，范围 360–1000px；实际布局会随视口调整。zoom、cluster、filter 与原版本兼容。
heading_level="1" 用于独立地图页主标题，默认使用二级标题；仅接受 1 或 2。
